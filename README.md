# 제인의 픽 · 대시보드 예제

내 업무에 맞게 바꿔 쓰는 단일 HTML 대시보드 3종입니다. Jane / Dante Labs가 기획하고 AI의 도움으로 구현한 자체 제작 예시입니다.

| 예제 | 파일 | 할 수 있는 일 |
|---|---|---|
| 재정 관리 | [finance.html](templates/finance.html) | 기간별 수입·지출·수지 비교 |
| 콘텐츠 운영 | [content.html](templates/content.html) | 채널별 기획·제작·검토·발행 현황 조회 |
| 매출 현황 | [sales.html](templates/sales.html) | 기간·채널별 매출·주문·객단가·환불 비교 |

## 시작하기
1. 저장소의 `Code → Download ZIP`으로 내려받아 압축을 풉니다.
2. `templates` 안의 HTML 파일을 브라우저로 엽니다. npm 설치나 서버가 필요 없습니다.
3. 필터를 바꾸고 지표·차트·표를 확인합니다.
4. 파일을 수정할 수 있는 에이전트에 HTML 파일과 [활용 가이드](GUIDE.md), 해당 [요청문](prompts)을 전달하세요.

HTML 첨부를 지원하지 않는 도구라면 파일을 작업 폴더에 넣고 경로를 알려주거나, 코드를 붙여넣으세요. 파일 내용을 실제로 읽었는지 확인하세요. GitHub 링크를 읽지 못하는 도구에는 다운로드한 파일을 전달하면 됩니다.

## 포함 범위
- HTML·CSS·JavaScript가 한 파일에 포함됩니다. 외부 라이브러리·폰트·이미지·네트워크 요청이 없습니다.
- 예시 데이터는 가상입니다. 금액·이름·일정은 실제 업무 자료가 아닙니다.
- 필터는 브라우저 화면만 바꿉니다. 새로 열면 초기화됩니다.
- 로그인·권한·DB·결제·실제 게시·서버 저장은 포함하지 않습니다.
- 콘텐츠 보드는 조회용입니다. 드래그 이동이나 작업 수정·저장은 지원하지 않습니다.
- 재정 수지는 기간 수입−지출이며 계좌 잔액·세후 이익이 아닙니다. 매출 객단가는 환불 전 매출÷주문 수입니다.

## 파일 구성
- `templates/`: 바로 열리는 HTML
- `prompts/`: 업무별 수정 요청문
- `GUIDE.md`: 에이전트에 전달하는 법·실제 데이터 연결 단계·검수 기준
- `LICENSE`: MIT 이용 조건
- `manifest.json`: v1.0.0 HTML의 SHA-256
- `tools/build.py`: 유지보수용 생성기. 수정 후 `python3 tools/build.py`로 HTML을 다시 만듭니다. 예제 사용에는 Python이 필요하지 않습니다.

## 이용 조건과 출처
자체 제작 코드이며 MIT로 제공합니다. 수정·상업적 이용 시에도 저작권·라이선스 고지를 유지하세요. 다른 UI 템플릿의 소스나 외부 이미지를 포함하지 않습니다. 내용과 실제 데이터의 적합성은 사용하는 프로젝트에서 검토하세요.

오류·개선 제안은 Issues에 남겨주세요. 실제 고객 정보나 API 키는 올리지 마세요.
